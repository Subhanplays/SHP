# White-Label Hosting Panel

A customizable hosting billing platform for selling game servers, VPS plans, bot hosting, and related services.

## What It Includes
- User registration and login
- Product catalog and checkout
- Coin balance and renewal system
- Pterodactyl panel integration
- Admin tools for branding, users, products, and payments

## White-Label Defaults
- Panel name: `Hosting Panel`
- Full name: `White-Label Hosting Panel`
- Brand colors, logo, favicon, and landing page content are editable from admin settings

## Setup
1. Install backend dependencies in `backend/`
2. Install frontend dependencies in `frontend/`
3. Copy each `.env.example` to `.env`
4. Configure database, auth, and Pterodactyl settings
5. Run the backend and frontend

## Notes
- Demo branding and personal identifiers have been removed from the defaults.
- Seed data should be customized for your own company before production use.
